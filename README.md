## Cách chạy ứng dụng
* Yêu cầu Python: Python >= 3.1x
* Hỗ trợ hệ điều hành: Windows, Linux (Ubuntu 26.04)
* Lệnh chạy ứng dụng:

```bash
# Với Windows
python -m venv venv
./venv/Scripts/activate.bat
pip install -r requirements.txt
python app.py
```

```bash
# Với Linux
python3 -m venv venv 
source ./venv/bin/activate
pip install -r requirements.txt
python3 app.py
```
